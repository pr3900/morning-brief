MORNING BRIEF — SECTION IMAGES
==============================

Drop one image per section into THIS folder (NewsAgent\signup\images\).

- Name each file EXACTLY as listed below (all lowercase, hyphens, no spaces).
- Preferred format: .jpg  (.png also works — the page tries .jpg first, then .png).
- Best shape: landscape, roughly 16:9 (e.g. 1200 x 675 px). Cards crop to fill,
  so a wide, horizontally-composed photo looks best.
- Until you drop a real file, a grey placeholder photo shows automatically —
  so you can add them one at a time.
